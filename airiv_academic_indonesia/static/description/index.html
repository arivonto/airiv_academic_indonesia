AIRIV Indonesia Academic Government Bridge

Indonesia Academic ERP & Universal Government Bridge

Academic, campus, school, and pesantren workspace for Odoo 18 with student registry, academic structure, KRS grading, batch education billing, and Indonesian government integration surfaces for PDDikti, Dapodik, EMIS, PIN, and SIVIL.

Odoo 18 CommunityEducation ERPPDDiktiDapodikAIRIV

Core Capabilities

AIRIV Academic Indonesia organizes Indonesian education operations into one Odoo workspace: master academic structure, student lifecycle, KRS and GPA tracking, education billing, and government reporting workflows.

Academic Core

Year, faculty, program, course

Manage academic years, semester types, faculties, programs, course credits, lecturers, and institution context.

Student & KRS

Lifecycle and grading

Track students, program placement, advisor, KRS lines, credit totals, semester GPA, cumulative GPA, and academic status flow.

Government Bridge

PDDikti, Dapodik, EMIS, PIN SIVIL

Configure sandbox or live profiles for Indonesian education reporting surfaces and execute batch synchronization wizards.

Feature & Workflow Automation

1

Build structure

Create academic years, faculties, programs, and courses before opening student intake.

2

Register students

Store student identity, NIM/NISN, NIK, contact, program, academic year, advisor, and lifecycle status.

3

Run academic term

Create KRS, approve submissions, lock grades, and compute total SKS, IPS, and cumulative IPK.

4

Report and bill

Use government sync and billing wizards for regulatory reporting simulation and education invoice generation.

Installation Guidance

Install

Add to Odoo addons

Clone branch 18.0, add the module folder to your addons path, restart Odoo, update the apps list, and install the module.

Configure

Prepare academic master data

Create academic year, faculty, program, and course records, then configure government bridge profile.

Operate

Run term workflows

Register students, create KRS, approve/grade study plans, generate education billing, and run sandbox government sync checks.

Configuration Checklist

DependenciesConfirm Base, Accounting, Mail, and AIRIV OS Core are installed.
Academic masterPrepare academic years, faculties, programs, and courses before importing students.
Student identityFill NIM/NISN, NIK, program, intake year, contact, and advisor data.
